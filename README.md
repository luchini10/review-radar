# ReviewRadar

ReviewRadar is an MVP product research app. Phase 1 sets up the Next.js App Router project with TypeScript and Tailwind CSS.

This phase does not include OpenAI integration, fake product recommendations, a database, authentication, or payments.

## Requirements

- Windows 10 or Windows 11
- Node.js LTS
- npm
- PowerShell

## Run Locally

From the repository root in PowerShell:

```powershell
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

If PowerShell blocks `npm`, use:

```powershell
& "C:\Program Files\nodejs\npm.cmd" install
& "C:\Program Files\nodejs\npm.cmd" run dev
```

## Available Scripts

```powershell
npm run dev
npm run build
npm run start
npm run lint
```
